# Playback

This folder owns Remotion playback of episode scripts and debate animation frames.

## Owns

- Remotion scene and planner-frame rendering
- camera and scene-object transitions
- caption, media, screen-fill, and zoom playback helpers

Playback consumes episode contracts from [Episode Script](../episode-script/📌README.md), planner frames from [Engine](../../../engine/📌README.md), and reusable render primitives from [Components](../../../components/📌README.md).
