# Episode Script

This folder owns the episode action schema, scheduling, compilation, and authoring reference.

## Owns

- episode action and scene contracts
- relative cursor scheduling for blocking and nonblocking actions
- graph action compilation, scene-object state resolution, and text-based duration
- the [standalone episode-authoring reference](./EpisodeAuthoringReference.ts)

Episode definitions consume these contracts. Remotion playback lives in [Playback](../playback/📌README.md); debate command application, scoring, layout, and geometry remain in [Engine](../../../engine/📌README.md).
