# Components

## Purpose

This package owns reusable React components for debate visualization and claim content. Debate graph geometry and layout are provided by `@reasontracker/engine`.

## Owns

- React and SVG rendering
- component styling and visual constants
- host-independent components shared by website and video packages

## Main Entrypoints

- `src/index.ts`
