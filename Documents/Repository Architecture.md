# Repository Architecture Map

This map shows the repository's folder containment and the Software packages' dependency directions. Area paths open their folders on this website; those pages list the contained files.

Arrows point from a package to a package it depends on. Solid arrows indicate a source import or a published asset. Dashed arrows indicate a `package.json` dependency with no detected source import or published asset.

The boundary report checks Software package directions and lists unexpected imports, unassigned Software files, and documented runtime path exceptions. Use search to find an area or folder.
